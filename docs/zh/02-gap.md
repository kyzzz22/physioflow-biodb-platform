# 合并系统缺少的部分（差距分析）

从业务功能、技术架构、数据模型三维度列出「PF × BioDB 整合平台」相对目标（设计→采集→存储→管理→分析→可视化）缺少的部分。

## 1. 业务功能缺口

| 缺口 | 现状 | 说明 |
|---|---|---|
| **数据管理（研究/项目级）** | 无 | 无「研究项目」概念；无法按研究/实验组织、检索、浏览数据；无数据字典界面 |
| **实验ID 显式化** | `protocolId` 存在但未映射到 BioDB 实验维度 | 会议核心需求：experiment + participant 二段标识 |
| **BioDB 数据浏览/管理面板** | 无 | PF 内无法查看 BioDB 已存数据、管理事件 |
| **脑波/真实设备整合** | Muse adapter 已完成代码实现和单元测试 | Muse 实机连接、真实数据采集及 BioDB 入库尚未验证；Muse S Athena（Gen 3）不在支持范围 |
| **分析管线** | 原型已实现并完成单元测试 | 真实数据与最新整合环境的综合确认尚未完成 |
| **可视化** | 历史曲线、特征面板和情感地图已实现 | 浏览器人工确认及真实设备流接入（D9）尚未完成 |
| **权限/数据安全在平台侧** | BioDB 有用户/权限，PF 侧无统一管理 | 缺平台级角色/权限/审计的整合视图 |
| **条件管理界面** | 协议承载但无专门浏览 | 缺「实验条件一览」（刺激集等）的用户视图 |

## 2. 技术架构缺口

| 缺口 | 现状 | 说明 |
|---|---|---|
| **跨系统标识贯通** | PF `protocolId`/participant ↔ BioDB `experiment`/participant 无自动映射 UI | 需实验/协作者映射层（配置 + 自动推导） |
| **流式推送** | Phase 1 是批量推送 | 缺运行中实时推送（缓冲 flush + 按窗口 JWT） |
| **PF ↔ BioDB 部署协同** | 独立部署 | 缺统一的部署/配置（docker 编排、环境变量、健康检查） |
| **错误/重试/恢复（推送）** | Phase 1 有 JWT 刷新重试 | 缺断网/重传/幂等的完整策略 |
| **导出整合** | PF 导出独立、BioDB 数据独立 | 缺「PF 会话 + BioDB 数据」的联合导出/归档 |
| **分析/可视化基础设施** | 无 | 缺数据管道、计算/训练模块、图表组件库 |
| **统一认证体验** | BioDB Google OAuth + token；PF local | 缺平台侧统一登录/授权视图 |

## 3. 数据模型缺口

| 缺口 | 现状 | 说明 |
|---|---|---|
| **`experiment` tag 维度** | BioDB 时序仅 participant+experimenter | 会议核心：加实验维度 |
| **实验元数据** | 条件在 PF 协议，BioDB 无实验级元数据 | 缺 experiment 元数据（名称、假设、IRB、协议 hash、时间） |
| **数据字典 schema** | PF 有 graphDataDictionary | 缺「时序通道 → 数据字典」的对接（channel 清单 → 字典） |
| **协作者 ↔ BioDB participant 映射** | `protocol.biodb` + settings 映射，无 UI | 缺映射管理界面 |
| **分析结果存储** | 无 | 缺分析结果/特征/模型的存储与回写（可作 BioDB 事件或新集合） |
| **事件与实验关联** | BioDB event 有 user_id（协作者） | 缺 event ↔ experiment 关联（加入 experiment 字段） |
| **时序缺失/质量问题** | 无 | 缺采集质量元数据（丢帧率、时间戳连续性） |

## 4. 优先级排序（影响 vs 成本）

| 优先级 | 缺口 | 影响 | 成本 |
|---|---|---|---|
| P0 | `experiment` tag 维度（BioDB 一行扩展） | 会议核心，二段标识的基础 | 低 |
| P0 | 实验/协作者映射 UI（PF 配置） | 让数据标识可用 | 低 |
| P1 | PF BioDB 数据浏览/管理面板 | 平台「管理」环节落地 | 中 |
| P1 | 真实脑波设备 adapter | 脑波整合 | 中高（依赖硬件） |
| P1 | 数据字典对接（channel→字典） | 数据可解释 | 中 |
| P2 | 联合导出/归档（PF 会话 + BioDB） | 数据交付 | 中 |
| P2 | 分析管线（预处理/特征/ML） | 平台分析环节 | 高 |
| P2 | 可视化（历史/实时/情感地图） | 平台可视化环节 | 中高 |
| P3 | 流式推送 | 实时体验 | 中 |
| P3 | 平台级权限/审计/统一认证视图 | 合规 | 高 |
