# Token

BioDB は、Google で本人確認した後に、用途ごとの JWT を使って API を認可する。

| 種類 | 取得方法 | 有効期間 | 使う場面 |
| --- | --- | --- | --- |
| Google ID トークン | Google Sign-In | Google 側の設定による | `/auth/google/callback` に渡し、BioDB のログイン JWT と交換する。 |
| 管理 JWT | Google ID トークンで `role: manage` を指定 | 10 分 | WebUI のユーザー・参加者・長期 API トークンの管理。WebUI は `sessionStorage` に `manage_jwt` として保持する。 |
| サービス JWT | Google ID トークンで `role: service` を指定 | 180 分 | 外部 Web サービスが、読取・イベント用 JWT を発行してもらう。 |
| 長期 API トークン | 管理 JWT を使って WebUI から発行 | 1〜365 日 | 計測プログラム、バッチ、デバイスなどが短期 JWT を取得するための認証情報。 |
| センサー書込 JWT | 長期 API トークン | 10 分 | センサーデータの書込み。 |
| センサー読取 JWT | 長期 API トークンまたはサービス JWT | 10 分 | センサーデータの読取り。 |
| イベント JWT | 長期 API トークンまたはサービス JWT | 10 分 | イベントデータの作成・読取・更新・削除。 |

## 使い分けと理由

- **管理 JWT** は WebUI 操作にだけ使う。期限を短くして、ブラウザ内の認証情報が漏えいした場合の影響を小さくする。
- **長期 API トークン** は、Google ログインを対話的に行えないデバイスやバッチのために必要になる。このトークンを認可対象の API へ直接渡すのではなく、短期 JWT の発行にだけ使う。
- **センサー／イベント JWT** は、操作種別、対象参加者、利用できる時間帯を限定して発行する。Sensor/Event API は JWT の署名を検証するだけで認可でき、長期 API トークンを受け取る必要がない。短期 JWT だけをデバイスへ渡せば、漏えい時の利用可能範囲も 10 分間の指定操作に限られる。
- **サービス JWT** は、Google ログインを使う外部 Web サービス向けである。長期 API トークンを保持せずに、読取・イベント用の短期 JWT を発行できる。

JWT は `Authorization: Bearer <JWT>` ヘッダーで API に渡す。

長期 API トークンは発行時だけ返される。サーバーにはハッシュだけを保存するため、クライアント側で安全に保管する。

## 関連する設定値

- `APP_JWT_SECRET_KEY`: 管理 JWT、サービス JWT、センサー／イベント JWT に共通の署名・検証用共有秘密鍵。Auth API が発行・検証し、Sensor/Event API が検証する。トークンではない。
- `APP_SECRET_KEY`: Flask のセッション Cookie 用の署名鍵。現行のログインフローでは Flask セッションを使用していない。
