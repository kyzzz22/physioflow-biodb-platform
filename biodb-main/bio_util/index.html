BioDB util 数据把握・确认

传感器数据的可视化确认工具（NGINX 静态分发 + CSR 绘图）

工具列表

工具说明
简单数据检查器按时间段读取并绘制历史传感器曲线（多通道）
实时数据检查器每 1 秒拉取最近 10 秒数据，实时滚动曲线
事件 + 时序绘图时序曲线叠加事件标记（开始/结束/标记），联合导出
情感地图将选定通道的均值映射到情感坐标（冷静-兴奋 / 消极-积极）

使用说明

  • 需要先在 WebUI（/WebUI/）登录并获取长期 token（user_id + token）。
  • 输入 participant_id 与时间范围后，工具会自动用长期 token 换取 sensor_read JWT 再读回数据。
  • 配置保存在浏览器 localStorage，无需重复输入。
  • 时间范围不能超过长期 token 的授权范围（超出时后端会拒绝）。
